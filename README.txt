Inside of the text files put in 0 and then an empty line for an empty file.

However if a text file needs something in it put the number of the total named items.
And after put in the name of the items and then a comma(,) and then the total amount of that item each on a new line.
And then put an empty line.
An example would be:
-------------------
0

-------------------
1
Fridge,5

-------------------
2
Fridge,7
Computer,4

-------------------

You do the same for the fileNames.txt file however you put the number of files.
Then put the name of the files each on a new line/
And then put an empty line.
You can have a file be any name as long as it has a number and then .txt at the end.
An example would be:
-------------------
1
file1.txt

-------------------
2
tree2.txt
file3.txt
